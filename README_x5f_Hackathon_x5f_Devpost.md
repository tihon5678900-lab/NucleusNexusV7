### Inspiration
In the age of AI-driven anxiety, people need not just information but **peace**. NucleusNexusV7 started as a healing frequency web app (386Hz) on GitHub Pages. For this hackathon, we evolved it into a **Personal, Always-On, Private AI Healer** that keeps your emotional data under your control while using open AI infrastructure.

### What it does
1.  **Emotion-Aware Healing Chat:** User types how they feel (e.g., "I'm anxious before sleep"). 
2.  **NVIDIA Nemotron on Nebius Token Factory** analyzes the emotion and generates a personalized healing affirmation + breathing exercise.
3.  **GOLDEN 386Hz Engine:** Automatically plays and modulates the 386Hz healing frequency based on AI's response. The frequency intensity changes with the user's emotional state.
4.  **Private Memory:** Uses persistent memory (local + Nebius Serverless) to remember your healing journey without sending data to big tech clouds.
5.  **One-click deployment:** Runs entirely on Nebius AI Cloud / Token Factory.

### How we built it
- **Frontend:** Original V10 (HTML5, Web Audio API for 386Hz oscillator, Canvas for golden particle visualization) hosted on GitHub Pages: tihon5678900-lab/NucleusNexusV7
- **AI Brain:** NVIDIA Nemotron-4-Mini / Nemotron-3-8B served via **Nebius Token Factory**. We use Nemotron Nano for fast daily check-ins and Nemotron Super for deep reasoning when generating personalized healing plans.
- **Infrastructure:** 
  - Nebius Token Factory for LLM inference
  - Nebius Serverless Endpoints to deploy the app
  - Nebius Serverless Jobs for background processing of user healing history
- **Privacy First:** All healing conversations stay on Nebius independent infrastructure, not locked-in hyperscalers.

### How to Run Locally
1. Clone: `git clone https://github.com/tihon5678900-lab/NucleusNexusV7.git`
2. Get your Nebius API Key from https://console.nebius.com/
3. Open `index_V11_AI_Healer.html`
4. Paste your Nebius Token Factory endpoint + key in Settings
5. Open in browser - allow audio
